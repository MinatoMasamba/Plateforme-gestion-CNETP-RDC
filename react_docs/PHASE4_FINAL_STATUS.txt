🎓 LESSONS LEARNED

1. App Naming
   • Python module "mobile" conflicts with Django app name
   • Solution: Used "mobileapp" instead, with proper path in config

2. ViewSet Routing
   • ViewSets use @action decorator for custom routes
   • Reserved methods (list, update) cause conflicts
   • Solution: Use proper @action(detail=False) patterns

3. User Types
   • Two parallel user systems: User (Django) + PublicUser + Expert
   • Allows independent tracking of both types
   • Requires careful permission checks

4. JWT vs Sessions
   • Web uses Django sessions (cookies)
   • Mobile uses JWT tokens (no cookies on mobile)
   • Requires separate authentication paths

5. Security
   • ActivationToken: One-time use prevents replay attacks
   • Device fingerprinting: Detects unauthorized access
   • Quiet hours: Respects user privacy preferences
