🔐 SECURITY ARCHITECTURE
═════════════════════════════════════════════════════════════════════════════

Authentication Flow (Automatic):

1. User Login
   ├─ Submit credentials to Django
   ├─ Django authenticates
   ├─ Django creates session
   └─ Sets sessionid cookie

2. React App Loads
   ├─ Gets CSRF token from meta tag
   ├─ Stores in React context
   └─ Ready to make API calls

3. API Calls from React
   ├─ Fetch /api/v1/endpoint
   ├─ Include X-CSRFToken header (from meta tag)
   ├─ Include Cookie: sessionid (automatic)
   └─ Django validates both

4. Response
   ├─ Django checks CSRF token
   ├─ Django checks session
   ├─ Both valid → 200 OK
   ├─ Invalid → 403 Forbidden
   └─ Expired → 401 Unauthorized

Implementation:
  ✓ django-csrf.ts: getCsrfToken() function
  ✓ client.ts: Automatic header injection
  ✓ useAuth.ts: React hook for auth state
  ✓ base.html: CSRF token in meta tag
  ✓ Zero manual token management

Example 1: Get Current User

    const { user, isAuthenticated } = useCurrentUser()
    
    if (!isAuthenticated) return <Login />
    
    return <div>Welcome, {user?.full_name}</div>
  }

Example 2: Make API Call

    const result = await apiPost('/api/v1/votes/', { choice })
    // CSRF token + session auto-included!
    return result
  }
