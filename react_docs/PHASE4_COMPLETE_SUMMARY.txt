🗄️ DATABASE MODELS (7 MODELS)
═══════════════════════════════════════════════════════════════════════════════

1. ActivationToken
   ├─ token: CharField (unique, cryptographically secure)
   ├─ expert: OneToOneField (unique expert per token)
   ├─ created_at: DateTimeField
   ├─ expires_at: DateTimeField (7 days expiration)
   ├─ is_used: BooleanField (prevent reuse)
   ├─ used_at: DateTimeField (nullable)
   └─ Methods: generate_token(), create_for_expert(), is_valid()

2. PublicUser
   ├─ user: OneToOneField (to User)
   ├─ province: CharField
   ├─ profession: CharField
   ├─ phone_number: CharField
   ├─ last_login_device_type: CharField
   └─ created_at: DateTimeField

3. PushToken
   ├─ user: ForeignKey (to User)
   ├─ token: CharField (unique per user, device)
   ├─ device_type: CharField (android/ios)
   ├─ device_name: CharField
   ├─ is_active: BooleanField
   ├─ last_used: DateTimeField
   └─ created_at: DateTimeField
   └─ Index: (user, is_active), (user, token)

4. Notification
   ├─ id: UUIDField (globally unique)
   ├─ user: ForeignKey (to User)
   ├─ title: CharField
   ├─ body: TextField
   ├─ notification_type: CharField (REUNION_INVITE, VOTE_OPEN, etc.)
   ├─ priority: CharField (LOW/NORMAL/HIGH)
   ├─ data: JSONField (extra context)
   ├─ is_read: BooleanField
   ├─ read_at: DateTimeField (nullable)
   └─ created_at: DateTimeField
   └─ Index: (user, is_read), (user, notification_type), (user, created_at)

5. NotificationLog
   ├─ id: AutoField
   ├─ notification: ForeignKey (to Notification)
   ├─ status: CharField (SENT/FAILED/BOUNCED)
   ├─ provider: CharField (FCM/APNs/WebPush)
   ├─ error_message: TextField (nullable)
   ├─ sent_at: DateTimeField
   └─ Index: (status, sent_at), (provider, status)

6. NotificationPreference
   ├─ user: OneToOneField (to User)
   ├─ enable_reunion_invites: BooleanField (default: true)
   ├─ enable_votes: BooleanField (default: true)
   ├─ enable_amendments: BooleanField (default: true)
   ├─ enable_norm_updates: BooleanField (default: true)
   ├─ enable_system: BooleanField (default: true)
   ├─ enable_payments: BooleanField (default: true)
   ├─ quiet_hours_enabled: BooleanField (default: false)
   ├─ quiet_hours_start: TimeField (default: 20:00)
   ├─ quiet_hours_end: TimeField (default: 08:00)
   ├─ digest_enabled: BooleanField (default: false)
   └─ digest_frequency: CharField (DAILY/WEEKLY)

7. MobileSession
   ├─ id: UUIDField
   ├─ user: ForeignKey (to User)
   ├─ device_id: CharField
   ├─ device_type: CharField
   ├─ user_agent: CharField
   ├─ ip_address: CharField
   ├─ last_activity: DateTimeField
   ├─ created_at: DateTimeField
   ├─ expires_at: DateTimeField (30 days)
   └─ Methods: is_valid(), update_activity()

🔐 SECURITY FEATURES
═══════════════════════════════════════════════════════════════════════════════

✅ JWT Authentication
   └─ Short-lived access tokens (15 minutes)
   └─ Refresh tokens (7 days)
   └─ Automatic token rotation

✅ Expert Activation
   └─ Cryptographically secure tokens (secrets.token_urlsafe)
   └─ Single-use tokens (is_used flag prevents reuse)
   └─ 7-day expiration
   └─ Email-based activation link delivery

✅ Device Fingerprinting
   └─ Device ID tracking (UUID)
   └─ Device type tracking (android/ios)
   └─ User-Agent header logging
   └─ IP address logging
   └─ Multiple devices per user supported

✅ Session Management
   └─ MobileSession tracks active devices
   └─ 30-day session expiration
   └─ Activity timestamp updates
   └─ Device change detection

✅ Password Security
   └─ Django password hashing (PBKDF2)
   └─ Password confirmation validation
   └─ No plain-text storage

✅ Notification Preferences
   └─ Per-user, per-type granular control
   └─ Quiet hours enforcement
   └─ Opt-in by default for sensitive types
