🔐 AUTHENTICATION & SECURITY

Architecture
├── Django manages: User authentication, sessions, CSRF
├── React gets: sessionid (cookie) + CSRF token
└── All API calls: Include both automatically

Security Flow
1. User logs in → Django creates session
2. React initializes → Gets CSRF token from DOM
3. React calls API → Includes:
   - sessionid cookie (automatic via credentials: same-origin)
   - X-CSRFToken header (from token)

Implemented
✅ getCsrfToken() - Retrieves Django CSRF token
✅ setCsrfHeader() - Adds to request headers
✅ djangoFetch() - Wrapper with full CSRF handling
✅ useCurrentUser() - React hook for authenticated user
✅ useRole() / usePermission() - Auth checks in components
