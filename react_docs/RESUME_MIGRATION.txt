✓ INTÉGRATION DJANGO
─────────────────────────────────────────────────────────────────────────────

Template index.html:
  • {% load static %} - Chargement template tags Django
  • {{ csrf_token }} - Protection CSRF auto
  • {% if user.is_authenticated %} - Authentification
  • {% static 'js/app.js' %} - Références dynamiques

Injection de contexte:
  window.__DJANGO_CONTEXT__ = {
    csrfToken: "{{ csrf_token }}",
    apiBase: "/api/",
    user: {% if user.is_authenticated %}{...}{% endif %}
  };

Résultat:
  JavaScript peut accéder au contexte Django
  APIs configurées pour pointer vers Django
  CSRF token disponible pour POST/PUT/DELETE
