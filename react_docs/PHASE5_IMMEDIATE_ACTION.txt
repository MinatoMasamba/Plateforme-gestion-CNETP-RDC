SIMPLE 3-STEP PROCESS
─────────────────────

STEP 1: Install React Dependencies
────────────────────────────────────

$ cd /home/minato/projet/frontend
$ npm install

✓ This installs Vite, React, Tailwind, all dependencies
⏱️  Takes ~3-5 minutes (first time only)
📦 Creates: frontend/node_modules/


STEP 2: Build React App
────────────────────────

$ npm run build

✓ This compiles React to JavaScript
✓ Outputs to: /home/minato/projet/web/static/dist/
⏱️  Takes ~1 minute
📦 Creates:
   - web/static/dist/js/main-*.js
   - web/static/dist/js/vendor-*.js
   - web/static/dist/css/main-*.css


STEP 3: Run Django + Verify
────────────────────────────

$ cd /home/minato/projet
$ source mon_env/bin/activate
$ python manage.py runserver

✓ Django starts on http://localhost:8000
✓ Visit: http://localhost:8000
✓ You should see the React app!

TROUBLESHOOTING (If Something Goes Wrong)
═══════════════════════════════════════════════════════════════════════════════

Problem: "npm: command not found"
Solution: 
  $ which node
  If empty, Node.js not installed. Install from nodejs.org

Problem: "Build failed"
Solution:
  $ rm -rf frontend/node_modules
  $ npm install --force
  $ npm run build

Problem: "Django doesn't find static files"
Solution:
  $ python manage.py collectstatic --noinput
  $ python manage.py runserver

Problem: "React not showing"
Solution:
  Check console for errors: F12 → Console tab
  Check that /web/static/dist/ has files:
    $ ls /home/minato/projet/web/static/dist/

ARCHITECTURE SUMMARY (For Reference)
═══════════════════════════════════════════════════════════════════════════════

Django (Backend)
  ├─ Manages: Users, Sessions, CSRF, Database
  ├─ Serves: /api/v1/* (REST API)
  └─ Serves: / (React HTML template)

React (Frontend)
  ├─ Manages: UI, Components, Display
  ├─ Uses: Django sessions (automatic)
  ├─ Includes: CSRF token (automatic)
  └─ Calls: /api/v1/* endpoints

Communication
  ├─ All requests: Include sessionid cookie
  ├─ All requests: Include CSRF token
  ├─ Response: JSON or HTML
  └─ Auth: Django native (no JWT for web)
