═════════════════════════════════════════════════════════════════════════════
🔒 SECURITY (Automatic)
═════════════════════════════════════════════════════════════════════════════

When you make API calls from React:

✅ CSRF Token is automatically included
✅ Session cookie is automatically included
✅ No manual token management needed
✅ No JWT complexity
✅ Django handles everything

Example:
  // React code
  const response = await apiPost('/api/v1/vote/', { choice })
  
  // Behind the scenes:
  // • X-CSRFToken header added (automatic)
  // • Cookie: sessionid added (automatic)
  // • Django validates both
  // • Response sent
