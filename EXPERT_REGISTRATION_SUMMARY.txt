🔗 ENDPOINTS API

GET /api/v1/expert-registration/structures/
  └─ Récupère toutes les structures disponibles
  └─ Response: List of Structure objects
  └─ Permission: AllowAny ✅

GET /api/v1/expert-registration/ctm/
  └─ Récupère tous les CTM (Sous-Commissions Techniques)
  └─ Response: List of {id, number, name, description}
  └─ Permission: AllowAny ✅

POST /api/v1/expert-registration/public_register/
  └─ Inscription d'un nouvel expert
  └─ Content-Type: multipart/form-data (ou application/json)
  └─ Permission: AllowAny ✅
  
  Champs requis:
    ✓ email (EmailField, unique)
    ✓ password (min 8 chars)
    ✓ password_confirm (doit match)
    ✓ first_name (CharField)
    ✓ last_name (CharField)
    ✓ structure_id (FK vers Structure)
    ✓ ctm_ids (List[int], min 1)
  
  Champs optionnels:
    ○ phone (CharField)
    ○ specialties (CharField, max 500)
    ○ cv (FileField, max 5MB)

🎯 FLUX D'INSCRIPTION COMPLET

1. Expert scanne QR Code
   └─ Pointe vers: http://localhost:8000/inscription-expert/

2. Frontend charge et récupère les données
   ├─ GET /api/v1/expert-registration/structures/ → Dropdown
   ├─ GET /api/v1/expert-registration/ctm/ → Checkboxes
   └─ Affiche le formulaire

3. Expert remplit le formulaire
   ├─ Email & Mot de passe
   ├─ Nom & Prénom & Téléphone
   ├─ Sélectionne structure (dropdown)
   ├─ Sélectionne 1+ CTM (multi-checkbox)
   ├─ Décrit ses spécialités
   ├─ Upload optionnel CV
   └─ Clique "S'inscrire"

4. Frontend envoie POST (multipart/form-data)
   └─ POST /api/v1/expert-registration/public_register/

5. Django valide les données
   ✓ Email unique
   ✓ Passwords match
   ✓ Structure existe
   ✓ CTM(s) existe(nt)
   ✓ CV valide (si fourni)

6. Django crée les objets
   ├─ User (username auto-généré, is_expert=True)
   ├─ Expert (status=PENDING)
   ├─ M2M: expert.ctm_choices.add(*ctms)
   └─ Sauvegarde CV dans media/experts/cv/

7. Réponse 201 Created
   {
     "message": "Expert inscrit avec succès...",
     "expert": {
       "id": 4,
       "email": "...",
       "first_name": "...",
       "last_name": "...",
       "status": "PENDING",
       "inscription_date": "...",
       "ctm_ids": [1, 2]
     }
   }

8. Frontend affiche message de succès
   └─ Redirection vers login ou page d'info

🚀 UTILISATION

### Récupérer les structures
curl http://localhost:8000/api/v1/expert-registration/structures/

### Récupérer les CTM
curl http://localhost:8000/api/v1/expert-registration/ctm/

### S'inscrire (sans fichier)
curl -X POST http://localhost:8000/api/v1/expert-registration/public_register/ \
  -H "Content-Type: application/json" \
  -d '{
    "email": "expert@company.cd",
    "password": "SecurePassword123!",
    "password_confirm": "SecurePassword123!",
    "first_name": "Jean",
    "last_name": "Dupont",
    "phone": "+243812345678",
    "structure_id": 1,
    "specialties": "Géotechnique",
    "ctm_ids": [1, 2]
  }'

### S'inscrire (avec fichier CV)
curl -X POST http://localhost:8000/api/v1/expert-registration/public_register/ \
  -F "email=expert@company.cd" \
  -F "password=SecurePassword123!" \
  -F "password_confirm=SecurePassword123!" \
  -F "first_name=Jean" \
  -F "last_name=Dupont" \
  -F "phone=+243812345678" \
  -F "structure_id=1" \
  -F "specialties=Géotechnique" \
  -F "ctm_ids=1" \
  -F "ctm_ids=2" \
  -F "cv=@/path/to/cv.pdf"
