# Module : Bibliothèque Publique (ValidationPublicModule)

## 1. Objectif du Module
C'est la vitrine visible sur internet de l’infrastructure CNETP pour la population. La création de normes est par définition publique, car toute la société civile et les industriels tiers doivent pouvoir comprendre et appliquer la législation ou l’usage optimal décrit dans les travaux de la République. Ce module englobe deux grandes phases distinctes de la vie d’une norme : le recrutement des objections, et l'archivage gratuit officiel.

## 2. L'Enquête Publique (Phase Suspendue ou Draft API)
Avant qu'une norme ne bénéficie du tampon du ministre (Sanction Finale de l'État), elle passe par une phase obligatoire baptisée "Enquête Publique" d'une durée d'environ 60 jours en RDC ou au niveau sous-régional.
- **Statut "En Attente Visuellement" :** Les normes en enquêtes se présentent avec un badge de draft temporaire.
- **Mécanisme d'Amendement Public :** L'interface publique offre un canal réglementé pour déposer les objections écrites par la population (Ex: Bureau d'études étranger). Ce portail est équipé d'un formulaire récepteur capable d’enregistrer la base de réclamation via l'API. C'est l'équivalent moderne du cahier de réclamations communal. 
- Les commentaires et remarques obtenus publiquement sont par la suite digérés par les experts lors d'un nouveau tour CTM le cas échéant.

## 3. Base Intégrale Homologuée (Le Journal CNETP)
La vocation finale de ce module :
- **Bibliothèque Gratuite :** Liste intégrale des publications validées avec sanction réglementaire.
- L'UI de la liste publique offre des outils pour un filtrage efficace du portail afin d'aider les entreprises de travaux (catégories SBR, Eurocodes appliqués, etc.) à filtrer ce qui les concerne.
- **Métadonnées de consultation :** La plateforme offre toujours : le titre officiel du répertoire, l’année, l'équivalence norme ISO (s'il y a lieu), la description d’entête du manuel.

## 4. Outils de Publication (Téléchargements PDF / API Access)
Pour l'assurance d'utilisabilité par les ingénieurs locaux non-connectés à haut débit :
- Ce module gère la compression et le téléchargement dynamique ou statique sécurisé de chaque document en PDF. Les fichiers PDF générés lors de la parution portent visuellement ou par watermark le code source national garantissant les contrefaçons au niveau de l'inspection du travail.
- Permet l'interopérabilité pour exposer le catalogue aux institutions extérieures via une architecture structurée.
